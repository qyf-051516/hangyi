# 航翼系统定位与角色权限

## 系统解决什么问题

航翼是面向机务维修场景的排班、合规校验和操作追溯系统。员工可以查看个人排班、提交调班或请假、接收审批通知、查看本人资质，并使用业务知识助手。管理员负责人员、排班、航班运行资料、审批、资质风险、统计、历史和审计。

本资料描述的是航翼系统当前实现，不替代单位正式运行手册、维修管理制度或监管要求。生产操作出现冲突时，以单位正式制度和管理员确认结果为准。

## 普通员工可以做什么

普通员工登录后可以查看首页、全员排班信息和本人未来排班，提交或撤回仍处于待审批状态的调班、代班与请假申请，查看通知和本人资质，确认符合条件的本人排班已完成，维护手机号、排班偏好和界面主题。

员工不能自行修改班组、岗位、航司授权、机型资质或管理员权限。这些资料由管理员统一维护，避免登录或注册时覆盖已经审核的业务信息。

## 管理员可以做什么

管理员可进入管理工作台，查看当日人员、排班覆盖、调班和请假待办、请假冲突、资质风险及最近操作。管理员还能维护人员资料和权限、编辑与发布排班、生成勤务与放行排班预览、审批申请、维护航班运行资料、查看统计和审计日志、导出排班总表。

危险演示能力受单独开关控制。生产环境的 demoToolsEnabled 应保持为 false，防止误重建或模拟业务数据。

## 管理员是如何产生的

小程序不内置固定管理员密码，也不会因为工号、姓名或手机号匹配而自动提权。首次部署时，目标员工先使用本人工号登录并绑定微信，再由部署人员在云开发控制台执行独立 bootstrapAdmin 云函数。系统已有有效管理员后，后续管理员由现有管理员授权。

管理员权限以服务端实时读取的 staff.isAdmin 为准。退出普通账号再登录管理员账号时，客户端会清理账号缓存，服务端也会重新校验当前 OPENID 绑定，不能复用上一个账号的权限结果。

## 数据与身份边界

小程序不直接保存 Java 服务地址和内部密钥。云函数从 settings 集合读取配置，并根据当前微信 OPENID 查找已绑定且在职的员工，再向 Java 助手传递可信身份。员工在请求中自行填写的 OPENID、工号、姓名或管理员标记都不能作为授权依据。

智能助手的普通员工知识与管理员知识分级存放。普通员工只能检索 EMPLOYEE 级资料，管理员可以检索 EMPLOYEE 和 ADMIN 级资料。
